## Question

Does communication add value *beyond* QMIX's global-state coordination, and how does VBC's variance-based bandwidth control achieve efficient hybrid value-decomposition + communication? This is the central question of the comm-vs-ctde project.

## Sources cited

- [VBC — Efficient Communication in MARL via Variance Based Control](../external-sources/vbc.mdx) (Zhang, Zhang, Lin; Harvard / Amazon / Toronto; NeurIPS 2019)

## Findings

### Summary

VBC is a **hybrid approach** combining QMIX-style value decomposition with learned communication, introducing **bandwidth constraints** via variance control. By penalizing the variance of exchanged messages during training and using confidence-based selective communication at execution, VBC achieves **2–10× lower communication overhead** than full communication while **matching or improving** over pure value decomposition.

**Paradigm**: CTDE + selective runtime communication.

> [!IMPORTANT]
> VBC is the key result for comm-vs-ctde: **global state during training is NOT sufficient for all coordination.** VBC+QMIX beats QMIX by ~20% win rate on SMAC — communication adds value even when the centralized mixer already has full state.

### Key Contributions

1. **Hybrid architecture** — first to explicitly combine value decomposition (VDN/QMIX) with learned communication. Local action generator produces Q_i from local obs; message encoders process others' messages; combiner aggregates by elementwise sum; mixing network produces Q_tot.
2. **Variance-based message control** — loss `L = Σ (y_tot - Q_tot)² + λ Σ Var(f_enc(c_i))` penalizes high-variance (noisy) messages. Convergence guarantee `||Q_tot - Q*_tot|| ≤ λNG`.
3. **Confidence-based selective communication** — send a request only when the local decision is ambiguous (top-2 Q-gap < δ₁); reply only when the message is informative (Var ≥ δ₂). No extra scheduler module (unlike SchedNet/ATOC).
4. **Strong SMAC results** — ~20% higher win rates and 2–10× lower overhead; emergent strategies (defensive lines, kiting, sacrificial decoys).

### Architecture

- **Local action generator**: GRU(64) processes obs+history → intermediate `c_i^t` (sent AND used locally) → Q_i.
- **Message encoder** (shared params): `c_j^t → FC(196) → LeakyReLU → FC(64)`; output dim matches Q_i for simple summation.
- **Combiner**: `Q_i(o_t,h_{t-1},.) = Q_i(o_i,h_i,.) + Σ_{j≠i} f_enc(c_j^t)` (no extra params).
- **Mixing network** (training only): VBC+VDN (sum) or VBC+QMIX (monotonic hypernetwork mixing on global state).

**Communication as correction**: local Q-values are the baseline; messages refine only when needed. Confident local decision → low message variance → no communication.

**Temporal pattern**: high communication at episode start (establish formations/roles), low mid-episode (execute plan), spikes when an agent dies and formation breaks. VBC learns to communicate **only when necessary**.

### Experimental Results (SMAC)

Tasks: symmetric (2s3z, 3s5z, MMM) and asymmetric (3s_vs_4z, 6h_vs_8z, 6z_vs_24zerg — hardest).

1. **Communication helps**: VBC, SchedNet, FC >> QMIX, VDN on all tasks.
2. **VBC matches/exceeds FC**: on 2s3z, 6h_vs_8z, 6z_vs_24zerg VBC > FC (filtering noise helps); elsewhere VBC ≈ FC with 2–10× less communication.
3. **VBC beats SchedNet**: adaptive > fixed scheduling.
4. **Hybrid > pure QMIX**: state mixing + communication > state alone.

**Emergent strategies**: 6h_vs_8z — defensive line at map edge; 3s_vs_4z — healthy Stalkers shield firing Stalkers (kiting); 6z_vs_24zerg — two-phase decoy/split (QMIX 0% win rate here).

### Comparison Table

| Aspect | QMIX | CommNet | SchedNet | VBC |
|--------|------|---------|----------|-----|
| **Communication** | None | Always (100%) | Fixed K/timestep | Selective (4–36%) |
| **Coordination** | State hypernetworks | Broadcast + mean pool | Scheduled broadcast | State mixing + messages |
| **Training** | Off-policy Q | Policy gradient | Off-policy | Off-policy Q (QMIX) |
| **Bandwidth control** | n/a | None | Scheduler | Variance penalty + thresholds |
| **Extra module** | No | No | Yes (scheduler) | No |

- **Communication baseline**: [CommNet](./commnet.md) — VBC is essentially the selective, off-policy, value-decomposed evolution of CommNet's idea.
- **Survey placement**: [MARL communication survey](./marl-communication-survey.md) — VBC as an early hybrid (bandwidth-limited, value-level integration, differentiable + regularized).

## Open questions

- Thresholds (δ₁, δ₂) and λ are task-dependent with no universal defaults — require coarse-then-fine search.
- Convergence bound trades optimality for efficiency (error ∝ λ).
- Tested only on SMAC; generalization to other domains open.

### Relevance to comm-vs-ctde project

VBC is arguably the **single most important** indexed paper for this project: it *is* the QMIX+communication hybrid the project explores, and it provides the headline evidence that **communication adds value beyond global state** (+20% win rate, VBC+QMIX > QMIX). Open contributions: information-theoretic analysis of *what* the messages carry that the state mixer misses; whether the variance penalty is the best bandwidth mechanism; and how the communication-vs-state tradeoff shifts as partial observability increases.
